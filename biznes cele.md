# Бизнес-цели

## 1. Монетизация

### 1.1. Через рассылку

- **Проверка Telegram** — платная услуга (проверка TG-аккаунта стоит денег).
- **Последняя переписка с каждым клиентом** — показывать в карточке последний диалог.
- **Дата последнего контакта в календаре** — указывать дату последнего касания и правило «не позднее чем / не раньше чем через N дней».
  Смысл: не дублировать рассылки одному и тому же клиенту.

### 1.2. Что продаём

Продаём не саму рассылку, а **рост продаж**. Рассылка — инструмент, деньги клиента — результат.

## 2. Доказательство роста продаж на маркетплейсах

На карточке клиента нужно **доказывать** увеличение продаж на маркетплейсах.

### 2.1. Материалы по продвижению

Найти в сети конкретные методики (без воды):

- **Яндекс Маркет** — seller docs / справка для продавцов: продвижение, буст, ставки, акции.
- **FlowWow** — seller docs / справка продавца: продвижение, витрина, платное размещение.

Сейчас рекомендации идут из DeepSeek («SEO, создание…») — слишком общие. Нужна **конкретика**: что именно сделать, чтобы увеличить продажи. Это чистый marketing / рост продаж.

### 2.2. Показать результат

После рекомендаций — **реальные цифры роста**: до / после, период, прирост заказов и выручки.

## 3. Как данные из «Клиенты» превратить в деньги

1. Берём данные из раздела **Клиенты**.
2. Даём конкретные рекомендации по продвижению на маркетплейсе.
3. Продаём **рост продаж** (результат), а не «услугу ради услуги».
4. Добавить **пост-мониторинг** — отслеживание показателей после внедрения.
5. Добавить **оплату** — привязка оплаты к подтверждённому результату.
