# План: автопубликация карточек на маркетплейсы + авто-дашборд из МоегоСклада

Источник: созвон 21.08.2026 (заказчик ↔ разработчик). Статус: требования зафиксированы,
идёт прототип. Следующий синк — понедельник; промежуточные результаты показывать сразу,
не накапливая («показывай, что получается, чтобы корректировали»).

## Цель

Система заменяет человека, который вручную переносит данные из МоегоСклада и заполняет
карточки на площадках. Две основные ценности:

1. **Автоматическое создание и публикация карточек** на всех площадках + синхронизация
   между ними.
2. **Аналитика и рекомендации по продвижению** — отдельно для каждой площадки.

## 1. Дашборд

- Дашборд формируется из МоегоСклада автоматически, без ручных шагов.
- Обновляется сам (авто-рефреш данных).
- Прототип: **два маркетплейса** (Flowwow + Яндекс) как источники данных, их цифры
  участвуют в расчёте дашборда.
- Понять, достаточно ли для аналитики просто доступа в МойСклад + кабинеты площадок.

## 2. Карточки товаров (флоу создания)

1. Пользователь выбирает наименование букета **из МоегоСклада** — букеты всегда
   сначала создаются там, значит состав уже известен системе.
2. Прикрепляются фотографии.
3. Система **генерирует описание**.
4. Пользователь выбирает площадки для публикации — маркетплейсы **и сайт**.
5. Для каждого ресурса — **свой алгоритм/адаптер**: например, для Flowwow система
   должна знать требования к описанию, к картинкам и т.д.
6. Синхронизация карточек между площадками.

## 3. Аналитика продвижения и рекомендации

- Рекомендации отдельно на каждую площадку (площадки работают по-разному).
- По Flowwow: есть большой архив — анализировать **корреляцию между содержимым
  карточки и её позицией** в выдаче.
- Изучать правила продвижения/размещения площадки и на их основе давать рекомендации:
  что сделано правильно, что нет.
- Отчёт по аналитике: воспроизвести существующий отчёт, отобразить нормально
  (цифры, диаграммы), и главное — система должна **сама автоматически получать**
  этот отчёт.

## 4. Заказы через API

- Поступил заказ на площадке → автоматически записывается в МойСклад (и далее по цепочке).

## 5. Доступы

- **Яндекс**: доступ есть, должно работать штатно.
- **Flowwow**: токен получен через службу поддержки, действует **около часа**;
  ссылка на скачивание — похоже, **одноразовая**. Задача: проверить, рабочий ли токен,
  и понять, какие данные по нему реально можно вытащить. Описание карточки на Flowwow
  уже закидывалось вручную (есть образец).

## 6. Telegram (дашборд Рассылки)

- Добавить **обычную загрузку картинок с компьютера** в сообщения Telegram.
- Лимиты Telegram на рассылки — жёсткие; тема **отложена**, делается отдельной
  доработкой (не в этом прототипе).
